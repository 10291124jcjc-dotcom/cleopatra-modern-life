# 01 · 写梗 / Writing gags

## 中文

### 公式

**古代场景 + 现代物件 + 古法对照物 + 结果**

| 要素 | 规则 | 埃及女王的例子 |
|---|---|---|
| 古代场景 | 一眼能认出的标志性地点 | 金字塔、尼罗河、狮身人面像、神庙、沙漠 |
| 现代物件 | 一眼能认出，越日常或越高科技越好 | 扶梯、水上摩托、卡丁车、得来速、投影仪、无人机、翼装、快递 |
| 古法对照物 | 画面里同时有人用古代的方式做同一件事，反差才大 | 工人拖石头 vs 扶梯；芦苇船 vs 水上摩托；马拉战车 vs 卡丁车 |
| 结果 | 每个梗要有一个看得见的结果 | 渔夫被浇一身水；战车追不上；工人抬头看一眼又继续拖石头 |

「古法对照物」是反差大不大的关键：只有女王坐扶梯，观众要想一下才笑；旁边有一群工人在拖石头爬坡，一眼就笑。

### 6 条规则

1. **每个梗用不同的现代物件，场景和类型尽量分散**：交通、餐饮、办公、通信、科技、极限运动、养生、物流、安防……同一类最好不超过两个。同一类出现多次时，场景和古法对照物必须完全不同（埃及女王里扶梯、水上摩托、卡丁车都和交通有关，但分别在金字塔、尼罗河、沙漠，对照物是工人、渔船、战车）
2. **反差要大**：现代物件越「不该出现在那里」越好
3. **主角永远一本正经**：好笑的是别人的反应或结果，不是主角的表情
4. **不用参考视频里已经有的梗**：学形式，梗自己想
5. **开场用最一眼就懂、画面最大的梗**（扶梯上金字塔）
6. **结尾用一个历史典故反转**（传说克娄巴特拉把自己卷在地毯里去见凯撒 → 快递员把地毯送到罗马将军帐篷里）

## English

### Formula

**ancient setting + modern object + old-way contrast + result**

| Part | Rule | Cleopatra examples |
|---|---|---|
| Ancient setting | An iconic place people recognise instantly | pyramids, the Nile, the Sphinx, temples, desert |
| Modern object | Instantly recognisable; the more everyday or high-tech the better | escalator, jet ski, go-kart, drive-thru, projector, drone, wingsuit, courier |
| Old-way contrast | Someone in the same frame doing the same thing the ancient way | workers dragging blocks vs the escalator; reed boat vs jet ski; horse chariot vs go-kart |
| Result | Every gag needs a visible payoff | fishermen soaked; the chariot can't keep up; workers glance up and keep hauling |

The old-way contrast is what makes it land at a glance: the queen on an escalator is a thought; the queen on an escalator next to a crew hauling stone uphill is a laugh.

### Six rules

1. **A different modern object every time, spread across categories** — transport, food, office, comms, tech, extreme sports, wellness, logistics, security…; ideally no more than two from one category, and when a category repeats, the setting and the old-way contrast must be completely different (escalator / jet ski / go-kart are all transport, but at the pyramid / on the Nile / in the desert, against workers / a reed boat / a chariot)
2. **Maximum contrast** — the more the object "shouldn't be there", the better
3. **The lead stays deadpan** — the laugh comes from the result or other people
4. **Don't reuse the reference's gags** — copy the format, invent the jokes
5. **Open with the biggest, most instant image** (escalator up the pyramid)
6. **Close on a twist from history** (Cleopatra smuggled to Caesar in a rug → a courier delivers the rug)

Write every gag as one row (gag · contrast · result · main camera move), check all eight together, then write the shots and prompts. The table above is ours.

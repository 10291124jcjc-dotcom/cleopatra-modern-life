## 中文

| 平台 | 用哪个版本 | 注意 |
|---|---|---|
| Instagram Reels | 9:16 只有现场声，在 App 里加歌 | 原声音量调到 20%~30% |
| YouTube Shorts | 9:16 只有现场声，在 Shorts 编辑器里加歌 | 压进视频的商用歌曲可能被 Content ID 认领 |
| X（Twitter） | 4:3 | 横屏在 X 上显示得更大 |

### 文案

- 不带表情符号
- 一句话点题 + 列出几个梗，让人想看完
- IG / YouTube 只给视频配文案；要讲制作过程、开源，放在 X 上讲

我们 IG 用的：

```
Cleopatra's modern life.

Escalator up the pyramid, jet ski on the Nile, camel drive-thru, and a carpet delivery for Caesar.

#aivideo #ancientegypt #cleopatra #egypt #aiart #aifilm #history #pharaoh #funnyvideos
```

### 标注 AI 生成

画面很像真实纪录片，建议在文案或平台的「AI 生成」标签里注明是 AI 视频。

The footage looks like a real documentary, so mark it as AI-generated in the caption or with the platform's AI label.
